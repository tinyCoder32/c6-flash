C6 Screen Designer

Firmware for the Waveshare ESP32-C6-LCD-1.47. Plug the board in, press Install, and it is done in about a minute.

This browser cannot flash. Open the page in Chrome or Edge on a desktop. Flashing needs a secure page: open this over https (or from localhost).

Needs Chrome or Edge on a desktop — Safari and Firefox have no Web Serial.

After it flashes

  1. The panel shows C6-Setup. Join that Wi-Fi hotspot from a phone or laptop — it is open, no password.
  2. A setup page opens by itself. Pick your network, type its password, save. The board reboots and shows its address on screen.
  3. Open that address — or http://c6.local/ — from any browser on the same network. That is the screen designer.

The ESP32-C6 is 2.4 GHz only, so pick a 2.4 GHz network.

The BOOT button

Tapnext screen
Hold ~1.5sreopen the Wi-Fi setup hotspot
Hold ~4spower off — press RESET to wake it

Each one fires when you let go, and the panel shows which is armed while you hold.

If the board is not offered

Unplug it, hold BOOT, plug it back in, release — that forces its download mode. Then press Install again and pick the usbmodem port.
